05 / 攻撃手法

総当たり攻撃シミュレーター

短いパスワードを、ありうる組み合わせを片っ端から試す「総当たり攻撃(ブルートフォース)」で実際に解読します。文字数が1つ増えるだけで、時間がどれだけ跳ね上がるかを体感してください。

設定

—総当たりの組み合わせ数
対象パスワード: ??? (設定を変えると新しいパスワードが選ばれます)
-------
0試行回数
0.0秒経過時間
0試行 / 秒
「総当たり攻撃を開始」を押してください。

なぜ文字数が重要なのか

組み合わせ数は「文字種の数 の 文字数乗」で増えます。英小文字26種類の場合:

  • 3文字 → 26³ = 17,576通り
  • 4文字 → 26⁴ = 456,976通り
  • 8文字 → 26⁸ = 約2,090億通り

1文字増えるだけで組み合わせは26倍になります。これが「短いパスワードは危険、長く複雑なパスワードは安全」と言われる理由です。
