暗号ラボ (crypto-vault-games) 引継ぎメモ
====================================================================

■ これは何か
VAULT LAB プロジェクトに組み込む、暗号の仕組みを遊びながら学ぶ
ミニゲーム集。index.html を重くしないよう、別フォルダに分離してある。

■ 配置場所
C:\Users\norin\crypto-vault\crypto-vault-games\
（index.html と同じ階層に、このフォルダごと置く）

■ ファイル一覧と役割
  hub.html              入口ページ。5ゲームへのリンク一覧。
  caesar.html           01 シーザー暗号（換字式・スライダーで解読）
  xor.html              02 XOR暗号（ビット演算の可視化）
  rsa-lock.html         03 公開鍵暗号の直感（南京錠メタファー、小さい数でRSA体験）
  hash-avalanche.html   04 ハッシュのなだれ効果（1文字変えると値が激変）
  bruteforce.html       05 総当たり攻撃シミュレーター
  shared.css            5ページ共通スタイル（学習教材風・装飾少なめ）

■ 触ってよい場所 / 触ってはいけない場所
  ◎ 自由に変えてよい
    - 各ゲームの <div class="wrap"> 内のテキスト（説明文・問題文・初期値）
    - shared.css の :root 内の色トークン（--bg, --accent など）
  △ 変えるときは注意
    - <script> 内のロジック部分。特に rsa-lock.html の
      N=33, E=7, D=3 は「7*3=21 ≡ 1 mod 20」が成り立つ組み合わせで
      成立している。数字を変えると解錠できなくなるので、
      変える場合は e*d mod φ(n) = 1 の関係を保つこと。
  × 基本触らなくてよい
    - bitgrid / cipher-strip などのCSSクラス名（5ファイル共通で使用中）

■ 依存関係
  外部ライブラリ・CDN・ネット接続は一切使用していない。
  file:// で直接ダブルクリックして開ける（オフライン動作前提）。

■ index.html との繋ぎ方
  index.html の </body> 直前に以下を1行追加するだけ：
    <a href="crypto-vault-games/hub.html">暗号ラボを開く</a>

■ 既知の注意点
  - hash-avalanche.html のハッシュ関数は教育用の簡易実装（FNV-1aベース）
    であり、実際のSHA-256とは出力が異なる。本文中にもその旨を明記済み。
  - bruteforce.html は「英数字混合 × 4文字」だと数秒〜十数秒かかる場合が
    ある。BATCH（1ティックあたりの試行数）は bruteforce.html 内で
    const BATCH = 400; として定義。重く感じる場合はこの数値を調整。

■ 次にやるとよさそうなこと（アイデア）
  - 各ゲームの右上に「進捗チェック」（クリアしたらチェックマーク）
  - モバイル幅での表示崩れの最終確認
  - VAULT LAB 本体のトーン・オブ・ボイスに合わせた説明文の微調整
